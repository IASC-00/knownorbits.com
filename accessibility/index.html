Accessibility

Last updated November 20, 2026.

We want everyone to be able to use this site.

The site aims to meet WCAG 2.2 level AA. It uses real text rather than text inside images, descriptive alt text on pictures, text colors checked for contrast, a skip link, and pages you can use with a keyboard. It works without JavaScript. The one small script only works out the Moon's phase.

We haven't had an outside audit, so something may still be missed. If you hit a problem, email hello@knownorbits.com with the page and what went wrong. We'll fix it and reply, usually within 2 business days.
